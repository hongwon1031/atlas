# Atlas Constitution

> 출처: [00. Vision & Constitution](https://app.notion.com/p/3cd9f036b307810c97cce841de115a37) (2026-08-31 동기화)

이 헌법은 Atlas가 사람과 AI의 작업을 조율할 때 지켜야 하는 불변에 가까운 운영 원칙을 정의합니다. 변경하려면 근거와 영향을 ADR로 기록해야 합니다.

## 헌법 조항

1. AI는 기본적으로 `main` 브랜치에 직접 push하거나 merge하지 않습니다.
2. 모든 코드와 문서 변경은 독립 브랜치와 Pull Request를 통해 제출합니다.
3. 작업 시작 전에 대상 Workspace, Project, Task를 명시합니다.
4. 프로젝트 간 코드, 문서, 비밀정보 컨텍스트를 섞지 않습니다.
5. 중요한 기술 결정은 ADR로 기록합니다.
6. 완료 주장은 자동 테스트 또는 명시적인 검증 근거를 포함해야 합니다.
7. 비밀키와 인증정보는 프롬프트, 로그, 저장소에 평문으로 남기지 않습니다.
8. 에이전트가 확신하지 못하면 추측 대신 질문하거나 보수적으로 중단합니다.
9. 비용, 토큰, 사용량 제한을 작업 배정의 입력으로 사용합니다.
10. 자동화 수준은 관찰 전용 → 제안 → PR 생성 → 제한적 실행 순으로 단계적으로 높입니다.

## 적용 원칙

- Workspace는 자격증명과 정책의 최상위 격리 단위입니다.
- 역할과 권한을 분리하고 작업에 필요한 최소 권한만 부여합니다.
- 프로젝트의 승인된 문서와 ADR이 에이전트 개인 메모리보다 우선합니다.
- 검증을 생략해 비용이나 시간을 절약하지 않습니다.
- 최종 merge와 MVP 범위를 넘는 배포는 사람이 결정합니다.

## 모든 Task의 Definition of Done

- 목표와 범위가 명확합니다.
- Acceptance Criteria가 모두 확인됐습니다.
- 변경 사항과 검증 결과가 기록됐습니다.
- 관련 문서가 업데이트됐습니다.
- secret 또는 다른 Project의 컨텍스트가 포함되지 않았습니다.
- 사람의 merge 승인이 필요하면 명시됐습니다.
